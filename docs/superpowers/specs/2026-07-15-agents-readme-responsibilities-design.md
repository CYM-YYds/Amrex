# AGENTS.md 与 README.md 职责拆分设计

## 目标

消除两份文件对仓库结构、算例布局和构建命令的重复描述，降低内容不一致的风险，同时保留 AI 执行任务所需的明确约束。

## 职责边界

- `README.md` 是项目事实的唯一说明来源，负责仓库结构、算例文件职责、编译运行方法和开发者入门信息。
- `AGENTS.md` 只负责 AI 的阅读顺序、任务范围、工作区保护、验证规则、仓库特有陷阱和默认上下文。
- `AGENTS.md` 通过要求首先阅读 `README.md` 获取项目通用信息，不再复制其内容。

## AGENTS.md 调整

保留以下内容：

1. 以具体算例为工作边界，以及开始任务时的文件阅读顺序。
2. 修改前检查工作区、保护用户改动、按风险验证结果等 AI 工作约定。
3. 构建、运行任务分别需要额外检查的配置和脚本。
4. 当前仓库特有的路径陷阱和默认开发上下文。

删除以下重复内容：

1. 仓库目录清单和典型算例目录结构。
2. `main.cpp`、`AmrCoreLBM.*`、`Kernels.H` 等文件的一般职责。
3. README 已提供的通用编译和提交命令。

## 工作区保护规则

删除自动执行 `git add -A` 和创建 `before codex` 提交的要求。新规则要求编辑前先检查 `git status --short`，把已有修改视为用户资产，不自动暂存或提交，也不覆盖无关改动。只有用户明确要求时才创建提交。

## 验证标准

- `AGENTS.md` 不再重复 README 的目录树、核心文件职责和通用构建命令。
- 所有 AI 专用约束和仓库陷阱仍然存在。
- Markdown 通过 `git diff --check`。
- 只修改本设计文档和 `AGENTS.md`，不改变代码或构建配置。
