# 独立视图的可编辑 Z 轴标题

目的：解决原生轴标题与刻度重叠，同时保留用户手动设置的原页面。

桥新增 `add_axis_title_view --source Slice3`，复用原切片创建独立布局，复制相机、轴与
显示配置，使用独立色带；仅在新视图清空 Z 标题，用左右两个 Text 管线显示。
文字可在 GUI 修改，不重算梯度，也不改原切片输入。标题位置按创建时相机计算，
后续旋转或缩放需手动调整。处理 Show 自动重标定共享色带的副作用，并比较原视图、
轴、显示与 LUT 的前后属性。

验证：普通 Python 回归 29 项通过（9 项需要 ParaView，跳过）；编译节点 ParaView
6.2.0 的独立视图回归通过，核对原标题、相机、色带与可见性，新增两个文字节点。
测试退出时 EGL 报已有活动纹理警告，测试返回 0；不涉及求解器数值验证。

Windows GUI 现场执行成功：原视图 14984 保留，新视图 18084、文字节点 18368/18415，
时间 2000；回执 `original_preserved=true`。预览确认左右 Z 不与刻度重叠。
