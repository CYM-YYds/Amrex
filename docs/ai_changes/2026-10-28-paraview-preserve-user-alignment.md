# 保留用户编辑的标题与色标，只更新对齐

用户修改标题内容及色标高度、长度后，标准 publication_vorticity 会重新应用默认文本
和布局，因此新增独立 `align_publication --source ... --view-id ...`。

复用提取的标题对齐算法，按当前字体、字号、粗斜体测量包围盒；保持四边居中和图框
间距 40 像素。保留文本、相机、色带、色标标题和竖直位置，仅将彩色条左右端点对齐
流场图框。无新增数据节点，使用已有属性事务在失败时恢复。不是自动重跑标准排版。

验证：普通回归 47 项完成（37 通过、10 跳过）；编译节点真实 ParaView 排版回归通过，
模拟用户自定义四边标题、色标高度和长度，断言文字及高度不变、色条左右端点精确匹配
图框，原相机、色带和数据节点集合不变；原导出与预览一致性检查通过。退出存在既有
EGL 纹理及 printf 警告，测试返回 0。不涉及求解器或涡量算法修改。

保持 0.05877110694。色条 x=0.32457872565、length=0.35084254871，宽度
740.2778 像素，与图框左右端点匹配。临时检查图和前后回执保留在 BOX3D_OSI
`runs/temporary/paraview_user_alignment/preview.png` 与 `result.json`，原正式导出不覆盖。
