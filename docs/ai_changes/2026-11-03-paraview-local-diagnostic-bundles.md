# ParaView 本地诊断与单包收集

目的：修复启动器只记录主窗口、服务SSH失败却没有远端日志时缺失关键证据的问题。

范围：ParaView Windows PS1 启动器与使用说明，不改变求解器、连接进程数或SSH重试策略。
复用现有启动编号与客户端stdout/stderr，服务窗口改由生成的PowerShell脚本落盘SSH输出并记录退出码。
归档逻辑由启动器唯一维护，生成服务脚本时复用同一函数；各进程使用不同归档名避免互相覆盖。
启动结束、异常及服务退出保存zip；collect_latest.cmd支持崩溃后一键补齐最新本地输出，
附带Windows应用崩溃/WER事件与收集失败说明，不再要求用户逐个挑选文件或复制窗口。

验证：PowerShell tree-sitter语法解析（含生成服务脚本）；Python测试语法与现有模拟回归：65项测试，51项通过、14项因缺原生PowerShell跳过。
当前节点没有原生PowerShell，相关原生测试跳过，Windows 5.1/GUI现场运行尚未验收。
新增原生回归覆盖模拟SSH输出、255退出码及zip内容，可在有pwsh的环境执行。
强制结束窗口可能不执行finally；已有日志可手动重打包。日志包不能保证捕获所有GUI内部消息，
不能提供SSH服务端内部拒绝原因，也不代表原有SSH断连问题已解决。
