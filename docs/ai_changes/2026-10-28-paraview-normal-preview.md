# 恢复普通 GUI 视图并匹配导出

用户现场截图显示原生 PreviewMode 导致画布明显缩小，上一版仅按 ViewSize/PNG 尺寸
验收不足。撤销 GUI 中的 PreviewMode，恢复普通铺满视图区的显示；显式同步 Qt
布局事件后读取实际 ViewSize，作为排版和导出的共同尺寸，不另设屏幕缩放。
批处理仍按 --image-size 设置布局；回执区分请求尺寸与实际匹配尺寸。
保留同尺寸导出不切换字号、相机和文字位置的逻辑。只处理新增页面，不改原页面。

验证：普通 Python 29 项通过（9 项跳过）；编译节点 ParaView 排版回归通过，
PreviewMode=[0,0]，2066×1066 导出与返回后同尺寸截图逐字节相同；旋度不变。
退出有 EGL 活动纹理警告，测试返回 0。GUI 视觉占用仍应结合现场窗口确认，
不再以渲染尺寸相同推断窗口内预览大小合理。

现场回执：目标视图 18084，PreviewMode=[0,0]；正常 GUI、matched_view_size 和导出
均为 2066×1066，已重新生成指定 PNG 并同步 JSON/MD。此操作退出 Qt 原生预览的
自定义缩放，原页面 14984 不作修改。
