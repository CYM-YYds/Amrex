# 当前涡量切片的参考图样式与导出

目的：在用户当前 ParaView Slice3 上实现参考图的白底、正交视图、四边坐标和底部水平色标，
直接调整当前窗口并导出高清 PNG。范围为桥接显示操作、回归和使用说明；不重新求导或改求解器。

实现：扩展既有 publication_vorticity 的 `--style reference`，桥版本升为 8。
保留默认 publication 的 Times/方形布局，新样式用 Arial、0.1 间隔坐标刻度、两端两位小数色标，
相机平移给底部留白，导出 2400×2640。隐藏目标视图中额外几何叠加，保留输入和管线；
复用已有的旋度模 Calculator，不生成另一条数值算法。坐标按实际截面命名，不照抄参考图的 Y。

用户参考图未提供归一化定义；发出选择后未收到答复，按已说明的默认值保留原始旋度、
仅固定显示范围 0–1，超出部分饱和；没有做最大值归一化或平滑。

验证：普通 Python 桥回归 28 项中 20 通过、8 因解释器条件跳过；编译节点解析旋转场显示回归
通过，确认新旧样式复用同一标量、数值范围不变、其他叠加被隐藏、Arial 和端点刻度正确。
当前 Windows 会话热更新成功，并在已有 Slice3 上完成导出；PNG 用实际图像检查确认矩形
轮廓叠加消失。当前切片为 y=0.5，坐标 x/H、z/H，H=1。

输入：BOX3D_OSI 的 job615364，`plt_256000`，step=256000，time=2000，读取层级 2。
原始旋度模范围约 [1.77e-15,25.6]。输出及 JSON/说明保存在该运行的 `figures/` 下，
名称为 `vorticity_slice3_reference_style_20261027.*`。截图只复现展示效果，不证明网格收敛，
也不将图片与用户参考图当作同一组物理解。

草图、GUI 回执和显示回归日志保留在
`projects/3Dcases/Computing_performance_test/BOX3D_OSI/runs/temporary/paraview_reference_export/`。
未改用户的两处求解器代码，不对现有日志和数值数据做清理。
