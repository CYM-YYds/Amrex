# 四边标题居中与统一间距

目的：替代同尺寸参考排版中手工指定的标题位置，减少鼠标微调导致的不对称。

扩展现有 publication_vorticity 的 reference + image-size 路径，投影切片边界到屏幕，
使用 VTK 文本渲染器测量实际字号的包围盒；上下标题水平居中，左右标题竖直居中，
文字边缘到图框统一 40 像素。以图框为基准，不宣称测得 CubeAxes 刻度标签外缘。
窗口/相机/字号变化后需重新执行排版。保持普通视图，不启用 PreviewMode。

验证：普通 Python 29 项通过（9 项跳过）；编译节点真实 ParaView 排版回归通过，
断言四侧间距、两组对称中心，以及导出后预览截图与导出文件逐字节相同。
测试退出有 EGL 活动纹理警告，返回 0。未改变求导、归一化或原始数值。
