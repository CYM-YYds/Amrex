# 算例开发副本复制脚本更新

目的：从当前 BOX3D_OSI 建立独立开发副本，避免旧脚本覆盖原算例或回退编辑器配置。

范围：仓库级 scripts/copyproject.sh；新增同级 BOX3D_OSI_dev 算例目录。

主要改动：源和目标改为命令行参数，增加 --dry-run，拒绝已有目标及源目录内目标；使用 Git 文件清单并排除运行历史、日志、checkpoint、构建产物和编译数据库。保留源 .clangd 的 AMReX 版本和索引选项，仅替换算例绝对路径。复制保留源码、配置、脚本、测试、后处理文件和历史文档；历史文档中的旧算例名称仍指原始开发历史。

验证：bash 语法检查通过；实际复制 165 个文件，除 .clangd 的目标路径外逐文件与源文件一致；副本所有 shell 脚本语法检查通过；重复复制被拒绝。未修改构建配置和数值路径，未编译或运行数值计算；副本需自行编译后运行，历史结果位于原算例。
