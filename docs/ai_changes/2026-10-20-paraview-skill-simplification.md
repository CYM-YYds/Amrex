# 精简远端 ParaView skill

目的：让 AI 快速掌握本仓库远端 ParaView 的环境与执行入口，避免每次加载历史排错、
特定作业和开发验收细节。

范围：仅修改 `.agents/skills/paraview/` 的说明与界面元数据；脚本、兼容软链、
应用安装、在线会话及算例数据不变。

主要改动：

- 主入口聚焦节点、应用环境、批处理/GUI 选择、最小命令和必要的输入输出检查。
- 两份使用参考分别维护后台执行与 GUI 操作；补充任意任务脚本的远端 pvbatch 执行方式，明确已有包装脚本只导出中心线。
- 安装、旧客户端手动加载及实现约束移到按需阅读的 maintenance.md；移除日常指令中的固定作业与历史会话快照，链接既有记录保留证据。
- 并行验证状态引用后续 MPI 记录，保留多 rank 中心线不能默认数值等价的限制。

验证：skill 格式校验、YAML 元数据解析、受影响 Markdown 本地链接与锚点、
新增 Shell 示例语法及 git diff 空白检查通过。仅文档修改，未启动 ParaView、
运行安装器或重放历史数据测试。
