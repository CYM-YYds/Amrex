# ParaView 服务SSH认证前恢复

目的：处理16:17启动包中预检成功但服务SSH立即退出255、启动器只重试监听查询的情况。
范围：Windows启动器服务握手与监听就绪检查，不修改求解器或服务进程数。

复用现有生成服务脚本与本地日志。服务SSH增加每次独立的verbose日志及10秒连接超时，
在握手记录完整且无认证成功、发送命令、认证失败或指纹错误时，对瞬断执行最多五次退避重试。
认证后255断线、139崩溃、日志缺失均不重放，避免重复远端服务。
监听就绪改为读取本次本地服务输出，取消与服务握手并发的查询SSH；最终退出码直接中止启动。
210秒本地等待覆盖6次10秒握手及4/8/16/32/60秒退避，不主动终止仍在运行的服务。
不能据此确定SSH入口关闭连接的内部原因，也不保证首次握手永不失败。

验证：启动器与生成服务脚本通过PowerShell tree-sitter语法解析；现有模拟回归通过。
新增原生PowerShell回归覆盖认证前关闭后恢复、认证后断线、认证拒绝、139及重试耗尽。
当前环境无pwsh，原生测试跳过；Windows端实际启动与网络故障恢复尚未验收。
