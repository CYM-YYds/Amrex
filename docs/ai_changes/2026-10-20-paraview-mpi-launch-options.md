# GUI服务进程数可配置

目的：解除启动器固定单进程限制，同时避免把串行pvserver启动成多个互不通信的服务。
范围：paraview Skill的PS1、服务包装脚本、路由测试及说明；不更换已有安装或操作用户当前服务。

- PS1增加ServerProcesses（1–256，默认兼容现有单进程）和RemoteParaViewPrefix；同一参数组
  用于版本/能力预检及实际启动，输出真实请求进程数。已有状态/客户端更新模式不启动MPI服务。
- 远端要求编译节点及绝对安装前缀。多进程只使用所选安装的bin/mpiexec，核对CMake导出的
  MPI构建信息；二进制包无配置文件时用其pvpython检查MPI控制器。单进程入口保持兼容。
- 不支持MPI、没有配套启动器或无法验证时提前失败；版本探测不启动多rank实例。
  环境隔离、参数数组与版本6.2.0匹配要求保留。

验证：新增4项路由回归覆盖配套mpiexec与带空格参数传递、串行包拒绝多进程、版本探测不启动
多rank、单进程兼容及非法进程数拒绝；全部桥接回归18项通过，4项需真实ParaView的测试跳过。
Shell语法、Python测试语法、文档路径与diff检查通过，PS1保留BOM/CRLF及原兼容软链。
编译节点默认环境单进程--version返回6.2.0，多进程预检按预期拒绝该串行环境。

限制：实际已安装的是aarch64的6.2.0串行构建（PARAVIEW_USE_MPI=OFF），并无已验收的兼容MPI
安装。本次提供配置与拒绝错误启动的机制，没有声称已启用多rank或测得提速；未启动新的GUI服务，
也未替用户构建MPI软件栈。实际多rank运行与Windows端新参数现场验收均待MPI环境准备后进行。
