# BOX3D_OSI 自重复性复测

- 目的：区分 OSI 单独运行的不确定性与锁步诊断额外 A-B 操作造成的差异。
- 结果：两份完全相同的独立 OSI 作业在 step 32、64 的全部 checkpoint 文件逐字节一致；回退通信参数组为 job 603686/603687，生产路径其余参数组为 job 603690/603691（仅关闭环境不支持的 GPU-aware MPI device-direct）。
- 结论：当前没有复现 OSI 自身的非重复性；step 64 的 OSI/锁步差异应继续从锁步额外操作与 GPU 异步依赖分析。
- 限制：当前环境对 `osi_mpi_device_direct=1` 会触发 GPU-aware MPI 断言，因此生产路径复测将该开关覆盖为 0；job 603688/603689 记录了该配置不满足运行环境的原因。
