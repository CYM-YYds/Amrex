# ParaView 当前窗口控制桥

- 目的：通过已有 SSH 账户向本机 ParaView 当前会话投递有限的操作。
- 范围：新增后处理目录中的客户端、超算端投递器和说明；不修改用户已有的连接脚本改动。
- 实现：SSH 后台轮询、GUI 主线程定时器执行；独立 0700 会话目录；原子发布、命令 ID 去重和结果回传；仅开放读取管线、修改/恢复背景。
- 验证：仓库 .venv Python 语法解析通过；模拟 ParaView/Qt 的管线读取、背景恢复、非法操作拒绝、错误回传通过；真实文件投递/回传和未完成命令覆盖保护通过；文档相对文件链接检查通过，git diff --check 通过。
- 限制：尚未在用户 Windows ParaView 5.11.2 中加载，PythonQt 与 SSH 免密接入仍待现场验证；不宣称已实现端到端控制。客户端脚本必须在 ParaView 内运行，不适用仓库通用 Python 环境。
