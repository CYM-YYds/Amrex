# BOX3D_OSI 每 32 步差异定位

- 目的：用独立 OSI 与锁步 OSI 的 checkpoint 每 32 步比较，找出首个出现差异的时间步。
- 证据：job 603661（独立 OSI）和 job 603663（锁步 OSI）使用相同输入与可执行文件；step 32 的 level 0/1 文件逐字节一致，step 64 的 level 0/1 DDF 不同而 level 2 一致。
- 结论：当前未额外阶段同步的运行时序下，首次观察到的差异步是 step 64。锁步作业在写出 step64 checkpoint 后停止。
- 限制：此前带 GPU 同步归约的详细阶段探针（603658/603659）会改变时序，所有阶段均一致；因此它不能定位未同步运行中的具体函数，只提示差异可能与异步执行或竞态有关。
