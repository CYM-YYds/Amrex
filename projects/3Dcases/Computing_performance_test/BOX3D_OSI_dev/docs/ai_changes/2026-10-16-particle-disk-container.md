# 静态二维圆盘容器及读写

目的：按用户确认的范围开放二维圆盘几何、AMReX 粒子容器和读写；不接入流体推进，不推广三维 IBM、运动、接触或润滑公式。改动仅在 BOX3D_OSI_dev。

## 实现

- 二维编译 LagrangeParticleContainer 和 AuxiliaryPointContainer，开放初始化、重分配、ASCII 输出、checkpoint 和标记诊断。编译数据库完整性检查包含两个容器源文件。
- 二维仅允许 `particles.shape=disk`（默认），三维为 `sphere`。沿用 `checkpoint.write_particles` 开关，二维默认关闭。启用时创建静态圆盘，默认直径为 32 个 coarse cell，圆周必须严格位于物理域内。
- 圆周等角生成，二维只使用 x/y 坐标，属性为 fx、fy、tz、xlocal、ylocal、area；area 表示最细网格单位下的弧长。质量和惯量报告采用单位厚度圆盘定义；不用于运动推进。二维不读入三维 .lpa 文件。
- 二维辅助几何为 x–y 平面的 180 个圆周点；尚无压力采样，cp 保持零。重网格时重分配两种容器，重启后重建静态辅助点。
- 复用 AMReX 的标记 checkpoint；容器封装 Checkpoint/Restart 增加 Geometry 元数据的写入和前置校验，保存维度、形状、半径、网格尺度及圆心。二维拒绝缺失元数据或错误形状，三维兼容旧 checkpoint。新增元数据由容器独占维护，生成时来自容器几何，读取时先校验再恢复；没有新增几何缓存。
- 三维球面生成和耦合模型保留原算法。二维的 IBM 力、运动、碰撞、润滑和压力采样接口继续编译隔离。运动刚体的速度、姿态历史 checkpoint 不在范围内。
- 粒子开关开启时，按现有 PlotFile 输出频率写标记 ASCII 文件；未增加输出频率或更改流体推进。

二维、三维 CUDA+MPI 编译均通过；编辑器数据库刷新为 DIM=3，包含两个容器源文件。Shell 语法、README 本地链接及 CRLF 感知的 diff 检查通过。

- 二维 64² 基网格、最高层编号 2，1/2 rank、多 Fab、192 个 coarse step，受控加密从第 32 步起触发；实际日志确认新建层、Remake 和清层。

- 二维 1/2 rank 和第 96 步从 2 rank checkpoint 在 1 rank 重启，最终全部标记坐标及属性逐值比较，最大误差为零。排序按空间坐标，排除 ID/CPU 元信息，ASCII 精度为 AMReX 默认的 15 位。
