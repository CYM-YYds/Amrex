# 直接构造物理边界薄面

- 目的：去掉先构造三维厚候选盒、再与物理面求交的中间过程，保持既有薄面写入集合。
- 实现：在 `grow(valid, nghost) & domain` 中直接固定非周期物理面坐标；
  再按当前 Fab 的 valid 贴壁方向，将面内区域限制在原近壁范围，最后复用
  `removeOverlap()` 去重。所有加入列表的区域都已是薄面，内部邻点仍直接读取。
  即使 valid 没贴当前面，也保留其他贴壁方向引入的切向 Fab ghost。
- 范围：只改边界缓存的几何构造和架构说明，不改边界公式、执行 kernel、mask、
  相位或缓存生命周期。用户已有的函数重命名及文档修改不纳入本次提交。
- 验证：生产 CUDA+MPI 构建通过（使用含用户函数重命名的现场源码）；
  作业 `613474` 为 `SUCCEEDED`，在 1/2 rank 各通过现有独立 GPU 测试 432 组，
  对独立厚盒参考的全部 grown 存储、27 分量均有限且 `linf=0`，涵盖全部周期组合、
  非均匀 Fab、canonical/OSI、相位、covered 筛选、平均后修复及布局重建。
  为适配用户现场函数重命名，独立构建脚本仅将提取的定义名称映射回原测试夹具名称，
  函数体直接取生产源码，未修改永久测试入口。
- 本次验证针对几何改写；未重新进行生产推进或性能配对，不将此前性能数字当成本次实测。
  源码、构建及测试现场保留在
  [实验目录](../../runs/boundary_direct_faces_20261015/)。
