# 重构成本定量归因

## 目的与实现

回答 BOX3D_OSI 的重构成本来自数据准备、布局规划还是数据重建，并单独测量已删除
有限值检查的开销。基线为 `673305f`。本次只补齐现有、默认关闭的
`performance.regrid_detail_timing`，不改变数值核、AMR 判据、迁移或缓存策略。

完整计时关系如下，报告使用相减后的独占阶段：

```
重构区间 = 完整平均下传及修复 + AMReX regrid + 缓存重建 + 外层剩余
AMReX regrid = ErrorEst + RemakeLevel + 新建/清除层 + 布局规划剩余
ErrorEst = 宏观量 + 速度 ghost + 涡量 + 打标/计数 + 其余
完整平均下传及修复 = 平均下传 + 边界修复
```

`regrid_remake` 包含辅助场分配、DDF 重映射/新区域初始化、交换与释放等；
其内原有 `interp_regrid_fill` 不再额外相加。布局规划剩余包含 tag 整理、缓冲、
聚类、嵌套约束和布局管理等，不能全称为 CPU 聚类。

## 实验与复现

材料集中于 `runs/temporary/regrid_quantification/round1/`。复现入口为
`scripts/temporary/regrid_quantification.sh` 和 `analyze_regrid_quantification.py`。
新矩阵包含完整父子阶段归因及独立旧检查回放，职责不同于原缓存优化矩阵；MPI
启动、hostfile 和命令记录复用既有 `osi_experiment_common.sh`。

- 当前程序与独立实验程序均为三维 FLOAT、CUDA+MPI 编译。
- 独立程序只在冻结副本 `probe/src/AmrCoreLBM_amr.cpp` 回放旧解码/NaN/Inf 扫描；
  生产源码不恢复独立检查开关，不增加对应替代路径。独立对象目录与生产对象隔离。
- 先对照修改前程序，检查开启同步计时及独立程序关闭旧检查时的动态 AMR DDF。
- B 工况固定为原 `622137/B` 的 step 128000 检查点、128³、最高 level 2、
  `regrid_int=32`、B 阈值。每次运行至 128640，排除首个 160 步窗口，统计
  128161--128640 的 480 步、15 次重构。关闭收敛、场输出、检查点写出及细分 OSI 计时。
- 在同一节点单 rank/单 GPU，以同一个独立程序进行四对旧检查开/关交替测试；
  另以生产计时程序重复三次同步阶段诊断。同步诊断与无诊断的整体计时分别报告。
- 提交前冻结入口、程序与源码；保留输入、命令、哈希、编译和运行日志、报告及
  必要检查点。`probe/tmp_build_dir` 是明确可删除的临时对象副本，不是运行依赖。

## 实测结果与定量结论

作业 `622773`，whshare-agent-67，NVIDIA A100-PCIE-40GB，单 rank。14 组应用与
汇总断言全部通过，调度状态 SUCCEEDED。开启同步计时及独立回放程序关闭旧检查时，
动态重构回归的逐层 valid/active 差异范数均为 0，检查点 DDF 数据文件逐字节一致。

四次无检查控制的 480 步平均 `perf.total=21.35314 s`、重构 `1.64595 s`，占
**7.708%**。三次同步诊断平均 `total=21.32844 s`、重构 `1.64561 s`；总耗时相对
无诊断控制相差 -0.116%，与无诊断计时分开报告。独占阶段如下：

| 独占阶段 | 每次重构 ms | 占重构 | 占完整推进窗口 |
| --- | ---: | ---: | ---: |
| 速度 ghost 准备 | 35.464 | 32.326% | 2.494% |
| Remake：DDF 重映射/新区域初始化及辅助场处理 | 30.098 | 27.435% | 2.117% |
| 完整平均下传，不含边界修复 | 26.490 | 24.146% | 1.863% |
| 缓存重建 | 7.812 | 7.120% | 0.549% |
| AMReX 布局规划剩余项 | 6.984 | 6.366% | 0.491% |
| 宏观量计算 | 1.669 | 1.521% | 0.117% |
| 打标/计数 | 0.459 | 0.418% | 0.032% |
| 粗层物理边界修复 | 0.444 | 0.405% | 0.031% |
| 涡量计算核 | 0.274 | 0.250% | 0.019% |
| ErrorEst 及外层剩余 | 0.015 | 0.014% | 0.001% |
| 合计 | 109.708 | 100% | 约 7.716% |

三次诊断的平均下传为 26.432--26.520 ms/次、速度 ghost 为 35.194--35.898 ms/次、
Remake 为 30.095--30.103 ms/次、布局规划为 6.962--7.009 ms/次。
新建/清除层在本窗口为 0。Remake 内原有 DDF 填充路径约占其 98.3%，不再叠加。

**数据准备/重建是主要成本。** 速度 ghost、完整平均下传和 Remake 三项合计
83.91% 的重构时间；含修复则约 84.31%。涡量核本身只占完整推进约 0.019%，
继续微调 curl 算术不是主要机会。

**只改拓扑管理收益有限。** 即使把整个“布局规划剩余项”消除，按本窗口成本
分布估算，也只降低完整推进约 0.49%；这还是把包含 GPU tag 整理的整个组归零，
并非已经证明纯 CPU 聚类占 0.49%。若把布局规划、整个 Remake 和缓存重建全部
归零，保持其他阶段及工作量不变，过于乐观的耗时下降上限约 3.16%。把重构所有
工作归零的上限约 7.71%。这些是成本上限，不是八叉树重写的收益承诺。

**旧有限值检查有可测开销，但不能解释全部差距。** 同一独立程序的四对开/关测试，
完整推进增加 0.839%、0.735%、0.756%、0.951%，中位 **0.798% / 0.17029 s**。
检查本体平均为 12.574 ms/次；重构占完整推进从 7.708% 变为 8.521%，增加约
0.812 个百分点。原 10.90% 长跑还含 strace，且是全程统计，不能与该后期窗口
直接相减、将全部差值归给有限值检查。

本次整次主 Arena 活跃分配高水位：无检查 16766 MiB、开检查 19221 MiB；池保留
高水位均 30254 MiB。它们不是全设备/进程显存峰值，也不提供峰值发生时刻。

## 论文比较边界

Jaber Table 4 的 A5 总重构为 48.357 s，其中重构前的平均/插值/归约分别为
22.863/10.612/2.755 s，合计 36.230 s（74.92%）；其余数组准备、块/邻接更新与
新子块初始化等约 25.08%。
论文也承担数据准备成本，不能把 GPU-native 理解为这部分免费。

论文 A5 为 64³、四层，当前 B 为 128³、三层；相同最细分辨率不代表相同加密
覆盖、步数、更新量或工作。论文 0.95% 是全程参考，本次是固定 B 后期短窗口。
不能用两者占比之比作为八叉树相对 AMReX 的因果加速比。

按论文及当前程序的 `dt=dx`、单位域换算，论文 A5 的重构物理间隔为 32/64=0.5，
B 为 32/128=0.25，B 每单位物理时间重构两倍。这是比较配置差异，不是块状结构
必然代价；本次没有修改重构间隔。论文 A5 到 t=1000 约 64000 粗步、2000 次重构
（推算），约 24.18 ms/次；当前后期短窗口为 109.71 ms/次。它们不是等工作量
对照，不能把约 4.54 倍每次耗时直接解释为实现低效倍数。

来源：`research/papers/GPU-native adaptive mesh refinement with application to lattice Boltzmann simulation/full.md`，
§4.4、Table 2--4；正式论文 DOI：10.1016/j.cpc.2025.109543。

## 结论口径

测量可以确定阶段占比、旧检查的因果开销和保持其他阶段不变时的乐观优化上限。
它不能把每一秒严格分成架构固有成本与尚可优化的实现成本；后者需要具体候选实现
在相同网格、数值语义和工作量下对照，不能仅凭计时归因。

本次结论限于上述三维 FLOAT 单 GPU B 后期窗口；不代表多 GPU、其他覆盖形状、
全程平均、物理收敛或整体精度验收。源码、独立回放补丁、构建命令及完整数据见
任务目录，最终原始结果为 `round1/job622773/report.json`。
