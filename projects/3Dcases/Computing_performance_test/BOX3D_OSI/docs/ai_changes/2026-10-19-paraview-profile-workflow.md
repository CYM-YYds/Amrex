# Re=1000 三维数据 ParaView 提取及对比流程

- 目的：验证 job613495 最新三维输出可正常处理，使用 Re=1000 的 Fig.18(a)，不误用 Re=3200 参考。
- 范围：新增 data_post_processing/extract_run_centerline.py，不覆盖旧 CSV 或图像，不改物理模型。
- 实现：自动选择运行目录中编号最大的 plt_；通过共享控制桥调用 ParaView 中心线导出，生成独立结果目录。分析校验真实几何 bounds、vtkValidPointMask、有限值、内部采样缺口，按 H 和 U_lid=0.05 归一化，与本地 digitized Fig.18(a) 数据对比并输出误差 CSV、PNG 和带哈希的报告。旧 160000 步 CSV 只作曲线形状参考，不用于时间收敛证明。
- 验证：Python 语法、仓库路径、模拟 CSV 的重复点聚合、无效端点剔除、内部缺口拒绝通过；暂存 diff 检查通过。
- 现场验证完成：当前 Windows ParaView 通过控制桥读取 job613495/plt_256000，level=2，三维 bounds=[0,1]^3；沿 (0.5,0.5,0) 至 (0.5,0.5,1) 均匀采样 1024 段，导出 1025 点。有效性掩码全部为 1，三分量速度均有限，坐标单调、中心线位置正确，底壁 ux≈0、顶壁 ux≈0.05。未安装 yt，也未使用其他 Python 环境运行后处理。
- 结果：相对 Fig.18(a) AMR 的 20 点 RMSE=0.0099868453、MAE=0.0060251177；相对 Cortes & Miller 的 44 点 RMSE=0.0202637986、MAE=0.0132428185，单位均为归一化 ux/U_lid，无排除参考点。
- 产物：data_post_processing/20261015_171801_job613495_step256000_paraview/ 下的原始 CSV、ParaView 回传元数据、误差 CSV、PNG 及带哈希的报告。新增 --reuse-export 支持只重绘和重新分析，不重复操作当前窗口；图例移至绘图区外，已检查成图。
- 判定：已验证该三维数据的中心线提取、导出及参考对比流程可用；不代表三维全域逐值正确或严格稳态收敛。
