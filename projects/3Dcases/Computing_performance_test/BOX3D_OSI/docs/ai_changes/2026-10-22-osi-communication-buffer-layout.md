# OSI 通信缓冲布局优化与五项候选对照

## 目的和最终改动

按同层调度、粗细层搬运、本地复制及打包访存的顺序测试优化空间。原始基线为 `016060f`。
最终保留 `AmrCoreLBM_osi.cpp` 中每个 tag 的 MPI 临时缓冲由 `[cell][q]` 改为 `[q][cell]`：
复用已有 `buffer_cell_index()`、Box 几何、offset、通信计划及缓冲，八处 pack/unpack 索引成对修改。
AMReX TagVector 的每线程 cell、线程内 Q 循环保持原样，使相邻线程的同一 q 缓冲地址连续。

覆盖同层通信、缓存插值/平均写回及临时 regrid 迁移。通信区域、消息字节数、Q、phase 映射、
MPI 调度、缓存所有权、物理公式、checkpoint 格式和生产 inputs 均不改变；没有新增状态或开关。
本轮其他候选恢复原实现，未将实验调度、额外 stream 或轴坐标缓存带入正式代码。

## 五项受控比较

每个候选在自己的同节点/GPU作业内与对应控制程序比较，三轮正/反/正配对。
AMReX 26.06、CUDA 12.8、GCC 11.3、HMPI 1.2、FP64、3D Q27、A100-PCIE-40GB。
真实 AMR 为 Re3200、128³、level 0/1/2、BF16、max_grid_size 64、每32步 regrid；
从同一96步 checkpoint 推进到608，统计192–576七个64步窗口，共448步。
关闭输出、fixture、收敛停止、锁步诊断及OSI嵌套细分计时；生产inputs未随实验覆盖参数改变。
逐窗口核对各层碰撞calls/launch_cells和全部工作计数；每指标取较慢rank再累计，不将rank时间相加。

下表是配对总耗时降低百分比的中位数，负数表示变慢。不同节点不混合绝对秒数。

| 候选及控制 | 2 GPU 真实 AMR | 4 GPU 真实 AMR | 决定 |
|---|---:|---:|---|
| 同层提前接收 / baseline | 0.207% | −0.039% | 无稳定整体收益 |
| 接收完成驱动 / early | −0.202% | −0.600% | 不保留 |
| CPC 本地复制及staging重叠 / baseline | 0.194% | 0.092% | 无稳定整体收益 |
| 本地轴坐标复用 / baseline | 0.062% | 未测 | 不保留 |
| tag内按分量连续 / baseline | **1.459%** | 另作最终核对 | 保留 |

- 接收完成驱动在2/4 GPU单层中分别降低total 6.923%/1.309%，但真实AMR未延续收益。
  该候选控制为early，不能将其百分比与其他节点的提前接收结果相加。
- 本地轴坐标复用的单GPU total仅降低0.014%，comm反而增加0.444%；本地核寄存器从51升到54。
- 缓冲布局的2 GPU真实AMR三组total均更快，降低范围1.251%–1.925%；comm中位降低1.902%，
  interp降低2.061%，average降低1.305%。单GPU的MPI路径不执行，total变化0.017%；
  4 GPU单层comm变化−0.026%，没有据此声称通用单层加速。
- CPC候选复用现有执行器，测试提前接收、本地copy与整块D2H重叠及H2D与send收尾重叠。
  此项未作为CPC分块流水收益的证据。

## 数值验证与最终程序

- 五个候选各14组64步基线/候选对照，通过52,970条逐步逐层完整阶段记录和6,460条迁移源分类记录核对；
  实际阶段层级为0/1，Linf=0。覆盖2/4 ranks、周期/六面非周期、整块/2 MiB staging及三种插值。
- 每个候选另做192步动态fixture，检查新建、重建、清层及再次建立；终态active DDF Linf=0。
  这些fixture终点为level 0/1，不将其冒充最终level 2的对照。
- 最终二维/三维CUDA+MPI构建通过。复用现有维度回归入口，作业617164的54次运行全部退出0，
  42项检查与12组基线控制通过；覆盖DIM2/3、mode0/1/2、1/2 ranks、周期/六面边界、OSI/A-B和动态生命周期。
- 最终程序另做3D三层64步fixture，CPU独立读取canonical checkpoint的10,948,608个DDF分量：
  level 0/1/2的全valid有限值Linf均为0，active/covered非有限值及非有限模式差异均为0。
  这是小网格fixture证据，不解释成生产128³全部covered/ghost有限或长期稳定。
- 非周期物理ghost来源诊断仍与原基线一致（3D最大0.01352278042、2D为0.02019539653），
  非物理来源分类无mismatch；没有修复或掩盖该既有差异。
