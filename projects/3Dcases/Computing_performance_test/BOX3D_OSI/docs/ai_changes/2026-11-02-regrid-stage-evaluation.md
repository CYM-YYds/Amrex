# 完整平均与 Remake 内部成本评估

目的：评估此前 26.49 ms 完整平均和 30.10 ms Remake 中哪些准备工作值得优化。按用户要求不调整速度 ghost；只在独立冻结源码中加分项计时，不改正式求解路径或替换正式程序。

- 基线为 `5cd88b7` 工作树，含用户已有的 advance 格式修改；原 diff 已冻结。历史参考程序为前次重构定量实验的 candidate，只用于三维小规模数值回归，不用于当前性能因果比较。
- 独立快照编译三维 FLOAT、CUDA，编译成功。job622982 在 whshare-agent-67 单 A100-PCIE-40GB、单 rank/GPU 完成，调度状态 SUCCEEDED，11 次应用退出码均为 0。
- 三次小规模运行覆盖周期非均匀种子和动态重构；独立诊断程序开/关计时与历史参考末态 level 0/1 的 valid/active 六种差值范数均为 0，两组各 2 个 DDF 数据文件逐字节相同。该范围不构成长期物理收敛或二维验收。
- 性能从同一 B step128000 检查点运行至128640，首160步不计；每组统计480粗步、15次重构。开关顺序为 off/on/on/off/off/on/on/off。逐层 calls/launch_cells、各窗口工作计数和加权更新量一致。
- 关闭细分时完整推进窗口均值21.357882 s，开启时21.351270 s，差 -0.031%。四对 on-minus-off 为 +0.061%、+0.000%、-0.134%、-0.051%；这是诊断扰动对照，不是优化收益。程序 Total Time、初始化与检查点读取不在该窗口内。
- 622974 因工作目录与相对日志路径不匹配未启动应用；622976 因冻结脚本未设执行权限未启动应用。修正启动方式和权限后以622982完成全部测试；前两者不进入结果统计。

## 平均下传

四次诊断均值，每次重构累计所有层对；均为带同步的阶段墙钟时间，不是硬件计数器或纯 GPU event 时间。

| 子项 | ms/次重构 |
|---|---:|
| 临时结果分配 | 0.086 |
| CPU任务标签生成及上传 | 13.468 |
| 缩放与平均核（含阶段同步） | 11.559 |
| OSI搬运计划建立 | 0.230 |
| 平均结果写回 | 1.292 |
| 未单列部分 | 0.068 |
| 合计，不含物理边界修复 | 26.703 |

任务建表与上传占完整平均的50.44%，四轮为13.435--13.492 ms。它每次在 CPU 为 Q27 每8个父单元构造一条 RestrictionBlockTag，再上传 GPU；不是数学平均本身。仅分配和搬运计划合计约0.316 ms，优先只做这两项缓存收益有限。建表组若完全消除，保持其他工作不变的总窗口时间节省上限约0.946%；实际候选只能消除其中一部分。

优先候选应是减少 CPU 每-block 标签生成和上传，例如 GPU 生成现有任务表，或使用紧凑的每-Fab 描述进行派发。单纯跨重构缓存需谨慎：该 B 窗口频繁改变层对布局，旧任务不能无条件保留。数值平均仍须保留，不能以界面平均替代完整平均。

## Remake

| 子项 | ms/次重构 |
|---|---:|
| InitializeOsiLevel（含失效、分配及地址/通信区域准备） | 1.064 |
| 新 DDF 全数组 NaN 写入 | 4.660 |
| 旧布局 DDF 重映射到新布局（含该调用内部计划） | 11.153 |
| 新区域及插值模板几何准备 | 0.087 |
| 新区域插值初始化（包含函数内部准备） | 0.511 |
| 未单列部分 | 12.570 |
| Remake 合计 | 30.046 |

迁移四轮11.124--11.186 ms，NaN初始化4.651--4.667 ms，新区域插值0.510--0.513 ms。此窗口新增区域插值占 Remake 约1.70%，不支持优先重写插值核。旧数据迁移比新区域插值更值得调查；全数组 NaN 写入也是真实额外遍历，但删除前必须验证新状态每个后续读取区域的初始化覆盖，尤其 ghost 生命周期，不能直接当作无条件可删。

12.570 ms 是总计减上述组的残差，包含尚未计时的辅助场处理、旧存储/缓存释放等，不能称为已经测得的“释放成本”。AMReX FabArray 清理在布局最后一个引用消失时会清除关联 FP/CF/FB/CPC 等缓存，但本次没有将其单独测出。后续应优先拆分这一残差及重映射调用内部，而不是把它归入插值或算作不可避免的数值成本。

## 结论与复现

本轮证明：完整平均的任务准备是具体瓶颈；该窗口 Remake 主要不是新区域插值。没有提交生产优化或声称已经加速，速度 ghost 未调整。完整优化收益仍需候选数值回归及同节点交替 A/B 验证。
