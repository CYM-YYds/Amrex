# BOX3D_OSI 二维静止圆盘 IBM

目的：将现有运行开关、直接施力和 Guo BGK 延伸到 DIM=2；改动限本算例。
二维默认 ibm.enabled=false，不改变原方腔初始/边界条件、AMR 阈值和纯流体推进。

主要改动：

- 复用已有圆盘生成器，ConfigureIbm 在两维均设置运行时形状和实际最细层半径；
  形状参数仍唯一使用 particles.shape，二维仅接受 disk，位置/半径使用物理单位。
- 将静止耦合入口、力场 SumBoundary、受力输出和重启配置从三维 guard 中移出。
  圆柱/球面、壁面模型、运动/碰撞等三维代码继续保持原维度限制。
- 共用已有四点 delta 核与 Guo BGK。二维独立插值/传播分支只访问 z=0、Fx/Fy，
  不把三维五层 z 循环投影到二维；area 槽保存细层格子弧长，积分单元面积为 dx_min²。
  面外转矩按 xlocal*Fy-ylocal*Fx 累积，输出力系数按单位厚度参考长度 2*r 归一化。
- 保留 IBM 支撑区强制最细化、布局一致性检查、半步力宏观量修正、checkpoint IBM 配置
  与标记保存，以及读取后 Define(AmrCore::GetParGDB()) 的动态布局重绑。二维耦合不生成
  未启用的压力采样辅助点，避免使用旧静态几何半径。
- 扩展同一个 scripts/temporary/ibm_switch/ 验证入口，使用 DIM 与 IBM_VALIDATION_DIR
  选择维度和实验目录，不复制一次性提交入口。分析器同时解码二维/三维 canonical FAB。

验证材料统一保留在 runs/temporary/ibm_2d/：修改前 0cf36bb 的两维程序与源码、
构建日志、输入、命令、二进制 SHA256、数值场、checkpoint、脚本快照和 JSON 报告。
d2/ 为二维验收；d3/ 为受影响共享接口的三维回归。它们都是临时验证实验，保留关键复现材料。

CPU 内核检查在既有 dimension_kernels_test 中增加二维解析契约：常数再现、面积量纲、
力和转矩反作用；DIM=2/3、FLOAT/DOUBLE 均经 ASan/UBSan 检查。GPU 结果见末尾验收记录。

边界：限静止单次直接施力。原方腔边界保持不变，不等同于入口/出口圆柱绕流；
短程有限值、近机器精度回归不证明物理收敛、长时间稳定性、性能、多节点或运动刚体正确性。
锁步使用共享力场比较推进布局；独立 A-B/OSI 与 MPI 运行补充其范围，physical ghost 仍单列。

## 二维验收

作业 626200，21 项检查通过，DIM=2/FLOAT，单精度粒子，单节点 1/2 GPU。
网格 32²、Re=100、32 个 coarse step，每 8 步 regrid、step16/32 checkpoint，step32 输出。
主比较 max_level=1，另有 max_level=0 同网格开关对照及 max_level=2 三层有限值检查。

- IBM 关闭对原二维程序、关闭/圆盘的连续运行对重启、旧纯流体 checkpoint 重启、
  圆盘 A-B/OSI、独立 OSI 对锁步、单/双 GPU、双 GPU overlap 开/关，
  均为相同拓扑下 canonical valid DDF 的 linf=0、unequal=0；不包含 ghost。
- 锁步阶段及重网格后 all-valid 检查通过；后者含 covered/interface。
  physical-ghost source 仍分列，不能将此结果外推为全部 ghost 相同。
- max_level=2 完成且 valid DDF、速度、受力有限；不声称三层严格 A-B 等价。
- 同均匀网格上 IBM on/off 最大 DDF 差 8.022785187e-5，确认实际流体作用。
- 51 个标记输出有限，物理半径最大误差 3.227847417e-8；格子弧长总和相对解析
  2*pi*8 的绝对差 1.756392336e-6。开启标记输出对流体 DDF 无改变。
- 错维度形状、模式、域原点、尺寸、解析度以及 checkpoint 几何/启用状态不匹配均拒绝。
  IBM 开启且 checkpoint.write_particles=false 仍保存标记，重网格后布局断言通过。

定量结果见 d2/verification.json；CPU 内核四种 DIM/精度组合全部通过。

## 三维兼容回归与收尾

作业 626201，三维现有 22 项检查通过。保持与上一轮相同的 Re=100、32³ coarse grid、
32 步及 regrid/checkpoint/output 设置。关闭 IBM 对修改前程序以及旧纯流体 checkpoint
重启仍逐值一致。球体/圆柱重启最大 DDF 差 1.490116119e-7，独立 A-B/OSI 与单/双 GPU
最大差 1.788139343e-7，overlap 对照 1.192092896e-7；通过原先的 FLOAT 容差。
三层圆柱 valid 场有限；不将这项检查描述为三层严格 A-B 等价。

构建入口对 DIM=2 和 DIM=3 均完成 CUDA+MPI/FLOAT 编译；命令与输出保留于
baseline_build.log、build2d.log、build3d.log。两维 GPU 检查均比较 canonical valid DDF，
要求相同 BoxArray，不含 ghost。源文件保留既有行尾，空白检查采用
`git -c core.whitespace=cr-at-eol diff --check`。Shell bash -n、Python AST、文档链接和
AGENTS 软链检查通过。用户已有的后处理、图片、PPT 和 MLUPS 文档修改未纳入本次提交。
