# OSI 单项优化与全开：分项耗时重测

目的：按用户修订方案，补齐基线撤回平均批量操作，并用同一基线分别测试平均＋插值批量、边界批量薄面、碰撞128线程、碰撞坐标复用，最后同时开启四项。展示累计分项墙钟和500步窗口耗时曲线，不沿用旧图的累加MLUPS归因。

范围仅BOX3D_OSI实验副本。现场正式源码有用户未提交的圆柱/边界/参考尺度等修改，读取diff后排除；从前轮job626333冻结源码扩展，正式源码、inputs、程序不改。前轮图表和原始证据保留，见[旧版记录](2026-11-05-optimization-ladder.md)。

## 实现与统计

复用 `scripts/temporary/optimization_ladder/` 的prepare/run/analyze入口增加 `--independent`；提交入口增加环境参数 `LADDER_INDEPENDENT=1`，不复制新的任务脚本。

统一OSI基线：平均和插值逐Box/任务发射、边界逐厚面任务发射、碰撞256线程、无碰撞坐标复用。每个单项只开对应优化；仅坐标复用仍为256线程，全开为128线程＋坐标复用。跨rank通信重叠关闭，碰撞批量不采用。

平均的两种发射方式共用同一GPU block标签、half-warp归约、线程映射和写回；逐Box分段启动的first_block沿已有标签顺序计算并检查覆盖所有block，覆盖正常界面平均与重网格完整平均。不新增持久状态，不撤回现役GPU任务表构建等其他优化。坐标复用补齐256线程分支，避免与128线程捆绑；所有浮点公式及求和顺序保持原实现。

同节点/单rank/单A100、FLOAT/D3Q27、Re1000、C阈值，从624717/C的step128000/t1000恢复，每次推进5000粗步到133000；动态AMR每32步重构，关闭输出与收敛检查，关闭嵌套OSI细分同步。首轮正序、第二轮反序，各配置两次，每次十个500步窗口全部保留。

每次总耗时为 `perf(s).total` 十窗口累加，含重网格，排除恢复、输出和窗口报告；图中使用两次5000步的均值。五项阶段墙钟为碰撞、边界、插值、平均、通信，其余为total减去上述分项，包含重网格未分列部分、OSI相位推进及调度等。各条不分别归一化为100%，图长使用实际秒数，旁注总耗时/基线总耗时；误差线/带为两次范围，不是置信区间，连续窗口不是独立重复。

## 验证与结果

作业626450，节点whshare-agent-82。新程序构建通过，六组64步动态AMR检查的9文件checkpoint均与参考一致；正式源文件未改。共享分析器回读旧主图日志，七行统计逐值不变。

首轮线程单项后半程同工作量500步窗口从约19s升至25s，原因尚未确认。保留该轮全部数据，同一分配内按反向顺序复测整个六组矩阵，并以1秒采样记录GPU温度、频率、功耗、利用率和事件状态。SSH诊断端口拒绝连接，未据此推断GPU故障；遥测由作业内执行。图表纳入两轮全部结果，不筛掉不利样本；线程单项的小幅均值差异需要结合两次范围解读。
