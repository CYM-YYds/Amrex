# Q=19 / Q=27 界面平均线程映射对照

目的：比较 Q=19 下整 warp、半 warp 与空间映射，并检验将 `is_scale` 固定为编译期常量是否有收益。
范围：正式 BOX3D_OSI 的 OSI raw → canonical 融合 restriction 内核；没有修改生产源码、配置或默认格子模型。

## 方法

生产模型仍为 D3Q27。实验先包含冻结格子表的 Q19/Q27 overlay，再利用头文件保护宏包含生产 `Kernels.H`；Q19 不是取 Q27 的前 19 项，而是使用已有 D3Q19 方向和权重表。

比较六种实现（带缩放仅比较前五种）：

1. `warp32_runtime`：一个 warp 一个父单元，调用生产 `average_down_osi_to_canonical_warp`，运行时 bool。
2. `warp32_fixed`：同一生产函数，编译期确定缩放值；作为独立 kernel 模板实例分派。
3. `half16_fixed`：半 warp 一个父单元，每线程持有 q=lane 和 q=lane+16 两个标量槽，16 线程归约；mask/width 限制在各自半 warp。
4. `spatial_serial`：一个线程一个父单元，调用现有串行生产函数；同 q 的相邻空间地址由相邻线程访问。
5. `tile8x4_fixed`：warp 内 8 个空间父单元 × 4 个 q 分组，每线程保存 ceil(Q/4) 个分量，跨 q 分组交换宏观量。
6. `spatial_q_noscale`：无缩放专用，按空间 × q 分派，不计算宏观量、不做跨 q 归约。

所有方案使用 ratio=2、缩放系数 1.73、两层 grown ring、相位 0/17/131；父盒形状为 `17×1×1`、`64×64×1`、`1×64×64`、`32³`、`64³`。
输入为带空间/方向非平衡扰动的正分布。不同盒形、相位共用同一确定性公式，包含发生环绕的地址与尾部不足整 warp 的情况。
基线的 ratio 在测试调用中固定为 2；生产捕获的 ratio 与编译器实际生成的完整求解器代码仍可能不同。

每个方案先与独立 CPU Qian 平衡态/八子单元求平均公式逐值比较，CPU 仅用 `e_host`，GPU 仅用设备表。
同时比较每个父单元密度和三方向动量的差值，拒绝非有限值。两项绝对误差阈值均为 `1e-12`。
所有 330 个“配置 × 方案”检查通过；最大分量误差 `2.220446049250313e-16`，最大密度/动量残差 `3.365363543395006e-16`。
这里的矩检查是与 CPU 参考输出比较，不是长期动力学守恒或稳定性证明。

计时使用 CUDA events，每轮连续启动 30 次，9 轮正反交替方案顺序；表内耗时为每次启动的中位数，加速比为每轮同条件基线/候选耗时之比的中位数。
GPU event 区间包含启动间可能的 GPU 空闲，不包含分配、编码、H2D/D2H、CPU 校验与初始化。小盒结果会受启动成本影响。

## Q19 带缩放结果

下表固定 phase=17；加速比大于 1 表示更快，倍数不是总求解器加速比。

| 父盒形状 | 基线 ms | 常量分派 | 半 warp | 单线程/父单元 | 8空间×4分组 |
|---|---:|---:|---:|---:|---:|
| 17×1×1 | 0.023996 | 0.996× | 0.996× | 0.611× | 0.724× |
| 64×64×1 | 0.040823 | 0.991× | 1.414× | 0.852× | 1.418× |
| 1×64×64 | 0.041779 | 0.992× | 1.413× | 0.672× | 1.383× |
| 32³ | 0.207258 | 0.992× | 1.650× | 1.952× | 1.847× |
| 64³ | 1.665502 | 0.983× | 1.737× | 3.101× | 2.419× |

三种相位下，半 warp 在两个薄片盒上为 1.374–1.414×，32³ 为 1.583–1.655×，64³ 为 1.635–1.737×。
空间映射收益受盒形影响明显：单线程/父单元在 64³ 达 3.101–3.121×，在薄片盒上却慢于基线。
因此不能根据“大立方盒上的最大加速比”替换真实稀疏界面路径。

Q19 编译资源（带缩放）：原整 warp 57 registers/thread，固定整 warp 56，半 warp 60，8×4 映射 85，单线程 255。
前三种及 8×4 无 spill；单线程版本有 400 B stack frame、404 B spill stores、624 B spill loads（编译器静态报告，非动态流量）。
单线程大盒仍然更快，说明不能只凭寄存器或线程空闲比例判断性能；确切瓶颈占比需要 profiler 证据。

## `is_scale` 与 Q27 对照

- Q19 带缩放时，整 warp 常量分派相对运行时判断没有收益，约 0.983–0.993×（非极小盒）；不应优先为去掉 bool 判断改写内核。
- Q19 无缩放、64³、phase=17：固定整 warp 1.085×，半 warp 1.630×，空间×q 专用 2.407×；专用线程映射的收益明显大于只固定 bool。
- Q27 带缩放：半 warp 在薄片盒约 1.365–1.411×，32³ 约 1.538–1.602×，64³ 约 1.713–1.914×。
- Q27 的单线程/父单元在测试的非极小盒都更慢，和 Q19 不同；其编译资源为 255 registers、1240 B stack、1192 B spill stores、1744 B spill loads。

## 判定与后续实施边界

**Q19 优先候选为半 warp；无缩放可单独使用空间×q 路径。** 半 warp 改动局部，在已测薄片及立方盒上均有收益，极小盒未见稳定收益。
空间映射可作为特定盒形的后续候选，现阶段不加入未经真实布局验证的尺寸阈值或自动分派。
本次只完成方案实验，没有替换正式平均内核；未改变通信、缓存、阶段同步或物理行为。

这些结果仅代表同节点、同 GPU、合成正分布、固定 ratio=2 的热数据内核级对照；大数据集虽超过 L2，仍未复刻真实稀疏 BoxArray 的工作集与调用分布。
不包含 `ParallelCopyOsi`、MPI、regrid 或完整 `average` 阶段，也没有进行 Q19 完整推进回归，不能据此宣称总程序获得同等加速或 Q19 求解器已经验证。
正式采用之前应在真实平均 BoxArray/相位分布上测累计 restriction 与整个 average 阶段，并执行实际数值路径的阶段逐值回归。
