# IBM 两项优化集成收尾

目的：将核权重复用及局部力汇总作为 BOX3D_OSI 的统一生产实现，结束验收期的新旧路径选择。
范围只限这两项优化，不提交工作区先前的绕流边界适配或其他用户修改。

## 现役实现

- 二维/三维 `force_interp_extrap` 在当前调用内计算一维四点核权重，插值与铺展共用，
  无跨步缓存；核支撑、力公式和邻域累加顺序保持原算法。实现提交 `aa2f3fd`。
- `SumForce` 根据实际标记点源 Fab 及支撑域接收 Fab 构造别名子集，复用 AMReX 本地/MPI
  累加，缓存随存储及粒子归属失效。实现提交 `c4ed2d8`。
- 删除 `ibm.local_force_sum` 字段、读取和整层生产分支；生产始终采用局部汇总。
- 保留 `ibm.enabled` 作为是否参与 IBM 的物理开关；保留默认 false 的
  `ibm.verify_local_sum`，仅在验收时额外执行整层参考、核对包含 ghost 的整个力场。
