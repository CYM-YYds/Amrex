# Restriction 标签去重实验

目的：比较原完整 block 标签与“区域属性一份、block 保存区域索引和起始单元”的空间与时间代价。
范围仅为 BOX3D_OSI 的独立冻结快照，不改生产实现和线程映射，不提交用户已有源码修改。

## 结论

本次布局的标签逻辑载荷降低约 76%，但单卡峰值只节省约 0.735 MiB，没有测出稳定的推进时间收益。
建议暂不合入生产。该建议限于本次短测，不排除更大界面布局下空间优化的价值。
双卡自动均值报告中的总耗时 -12.83% 不能归因于标签拆分：运行环境出现明显整体变化，其他未修改阶段也同时加快。

## 实验条件

- 基线：`d470c06` 加创建快照时用户工作区修改，完整差异保存在实验目录 `worktree.diff`。
- 两套程序均重新通过 CUDA/MPI 编译：AMReX 26.06、DIM=3、sm80、当前 Q27 半 warp 映射不变。
- 节点均为 whshare-agent-38，A100-PCIE-40GB；1、2 rank 分别在各自同一次分配内按 ABBAABBA 顺序运行，每种四次。
- Re=3200、64³ 基网格、level 0/1/2、max_grid_size=32、BF16、regrid_int=32、interp_mode=0、host staging。
- 从相同初态运行至 256 步，排除前 64 步；统计 65–256 步三个窗口。
- 多 rank 每窗口取较慢 rank，不相加；工作量记录（各层碰撞调用/单元数、平均调用等）一致。
- average 是完整平均阶段，含写回；total 含重构、不含初始化。不能由这些指标单独隔离新增索引访问的 kernel 时间。

## 空间与构建成本

独立 sizeof 实测：原 block 标签 80 B；候选 block 标签 16 B、区域标签 64 B。
区域有 B 个 block 时节省 64(B−1) 字节；多 block 区域的标签节省比例趋近 80%。

单卡每层标签范围如下；level 0 表示 level 1 → 0 的平均任务，level 1 表示 level 2 → 1。

| 粗层 | 原布局（B） | 分表布局（B） |
|---:|---:|---:|
| 0 | 40,960 | 9,216 |
| 1 | 625,520–975,440 | 146,992–236,752 |

单卡合计峰值从 1,016,400 B（0.9693 MiB）降至 245,968 B（0.2346 MiB），节省 770,432 B（0.7347 MiB，75.80%）。
这是设备标签逻辑载荷，不含分配器预留，不是整个求解器的显存压缩比例。构建期间还有 CPU 标签副本。
双卡逐层逐 rank 范围见 job619980/report.md；日志未显式记录 rank 编号，不将不同 rank 的各层极值拼成某个 rank 的实际峰值。

## 时间与稳定性

以下各项是 65–256 步的四次运行均值；正号表示候选更慢。

| ranks | 指标 | 原布局（s） | 分表布局（s） | 差异 |
|---:|---|---:|---:|---:|
| 1 | average | 0.272325 | 0.278677 | +2.33% |
| 1 | total | 10.583840 | 10.524835 | -0.56% |
| 2 | average | 1.535569 | 1.250638 | -18.56% |
| 2 | total | 16.262288 | 14.176425 | -12.83% |

这些均值不是已证实的优化收益：

- 单卡 average 的基线样本范围 0.209–0.326 s，候选 0.248–0.306 s；+6.35 ms 的均值差无法与运行波动分离，不能称为稳定的额外开销。
- 单卡 total 前一组 ABBA 为 -9.34%，后一组为 +8.92%，方向相反。总均值 -0.56% 不构成稳定加速。
- 双卡基线 total 在 trial 0/3/4 约为 17.9/18.7/18.3 s，trial 7 降至 10.13 s；分表 trial 1/2 约 17.6 s，trial 5/6 降至 11.50/9.96 s。通信、碰撞、插值也同时变化。
- 按目录命令及日志 mtime，单卡与双卡任务在同节点重叠运行；单卡约 11:59:10 结束，对应双卡后半段整体变快。但 GPU 快照的 PCI bus 不同（双卡 01:00.0、02:00.0；单卡 81:00.0），没有证据表明使用了同一物理 GPU。可能有共享节点资源干扰，其因果机制未被直接测量。
- 双卡末尾相邻的 split trial 6 与 baseline trial 7 为 9.961/10.129 s，只有一对，仍不足以确认稳定收益。

若未来确需以速度为理由合入，应串行安排两种 rank 配置或独占节点、增加稳定阶段交替重复，并单独测量 restriction kernel；当前不据此新增生产实现。

## 数值检查与边界

独立数值运行至 64 步，期间包含动态重构：

- 单卡 checkpoint 全部 8 个文件、双卡全部 11 个文件逐文件 SHA256 一致，包括 Header/Lattice 和三层 DDF 文件。
- 两个作业的首次界面平均前后 bin 和 mask 逐字节比较通过。
- 三层 active DDF 的 L1/L2/Linf 差为 0；level 0/2 valid 的这些差也为 0。
- level 1 输出 valid_linf=0，但 valid_l1/valid_l2=NaN。因此不能仅凭 Linf 为零宣称全 valid 有限或全 valid 数值范数为零。字节一致说明候选在该检查点保留了基线存储内容，包括非有限内容；不证明原算法所有区域都数值有效。
- 256 步性能运行正常完成，但没有对 256 步全状态做逐值对照，不将 64 步证据扩大为长期正确性结论。
