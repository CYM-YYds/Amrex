# 中文 OSI 原理逐帧图与动画

目的：将用户提供的 OSI 原理图转成可复现的中文逐帧图和 GIF，展示 7×7 分配盒、中央 3×3 valid、两层 ghost，以及非周期壁面处理。只涉及图示工具与文档，不改求解器、运行输入或现有实验。

实现：新增 `data_post_processing/plot_osi_principle.py`。现有后处理入口没有算法示意绘制职责，故新增独立绘图入口；GIF 编码与统一调色板直接复用 `pack_animation_gif.py`。逻辑网格和 OSI 原始存储并排，依次展示读取、寄存器碰撞、同址写回、通信检查、相位更新和壁面重建。方向编号采用 `LbmLattice.H` 的 D2Q9 排列0，寻址按 `OsiIndex.H` 的完整 grown-Fab 环。相位3→4时展示中心q1地址 `(0,3)→(6,3)` 回绕。

边界约定：用户明确选择非周期壁面；本图设四壁静止、单块物理域，valid边缘节点就是壁面节点，外侧两层是域外ghost。域外不从对侧周期填值。相位提交后，以新相位内部节点的分布函数和宏观量进行非平衡外推，写入新相位壁面地址；只突出右壁代表节点。颜色是处理阶段，不表示分布函数数值。底色是初始逻辑分区参照，不表示原始存储槽位永久拥有valid/ghost属性。

输出：`runs/temporary/osi_principle_animation/wall_final/`。正式保留本次图示与复现材料，包括126帧1400×1000 PNG、每帧350ms的循环GIF、六阶段关键帧PNG/SVG/PDF、总览、ZIP、逐帧地址清单、脚本和相关源码快照。这里的7个演示步不对应生产运行步数，也不读取流场数据，不做数值归一化。

验证：Python AST解析与参数帮助通过；绘图内检查14个相位、每方向环上双射、6174个pull地址恒等式与指定回绕。GIF合成器检查帧数与每帧时长；额外核对裁剪前后PNG像素相等，并检查关键帧视觉布局、中文字体和输出完整性。这是图示/地址验证，不构成生产求解器数值正确性证明。

复现命令与输出说明见 `data_post_processing/README.md` 的“OSI原理动画”。本次不提交用户已有的求解器与实验脚本修改。
