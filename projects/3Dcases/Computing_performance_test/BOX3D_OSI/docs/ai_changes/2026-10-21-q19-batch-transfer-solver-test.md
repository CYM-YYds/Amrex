# Q19：批量半 warp 平均与分量插值实验

## 目的与基线

在批量插值/批量平均正式合入的代码快照上，独立测试 Q=19 的进一步优化。正式配置仍为二维 Q9、三维 Q27，本实验不修改生产模型选择，也不与 Q27 的绝对耗时跨模型比较。

冻结目录：[`runs/q19_batch_transfers_20261021`](../../runs/q19_batch_transfers_20261021/)。实验源码仅将三维 LBM_Q 改为19，使用既有 D3Q19 order0 的完整19方向及对应权重，不是将 Q27 的后8个分量简单屏蔽。碰撞仍使用现有按 Q 展开的 BGK 实现。

基线 `00` 已经采用批量插值和批量32-lane界面平均；这里测的是批量化后的进一步收益。

## 候选与状态边界

- `10`：平均每16 lane处理一个粗父单元、每个warp处理两个父单元，lane0～2兼顾q16～18。保持全部19个分量、8个细子单元及缩放操作；归约次序与原32-lane路径在本次输入上产生相同结果。
- `01`：仅对interp_mode=0，将每个Box的每个q/空间block展开成任务，线程沿空间相邻单元排列；使用原三线性算式及原OSI写入函数。模式1/2仍原批量实现。
- `11`：两项同时启用。

实验开关 `verification.q19_half_average`、`q19_component_interpolation`、`q19_compare` 只存在于独立实验程序，初始化时读取。任务由既有布局缓存生成并随 `ClearOsiTransferCaches` 失效，执行时读取当前数组和phase。改变平均分组时同时改变标签中的父单元步长，原32-lane参考不使用候选标签。

插值参考从同一缩放后stage独立执行原逐盒插值，比较实际写入的fine target全部q；平均参考从同一fine输入执行原逐盒32-lane算法，比较全部interface结果。非有限值另行拒绝。候选和参考没有共享半warp数学实现。

## 构建及数值验证

- 构建作业 `616459`：所有9个算例翻译单元重新编译，仅复用相同三维AMReX对象；CUDA12.8/GCC11.3、AMReX26.06、FP64、sm_80。命令、源差异与日志保留。
- 主作业 `616462`：三种插值模式 × 1/2 rank × cavity/periodic，共12组，各64步、64³、最大Box32、max_level=2、regrid_int=32、动态fixture；周期组启用非均匀种子。每组基线与两候选均启用版本分别执行，独立于性能计时。
- 插值同源检查420次、平均420次，最大误差均为0，非有限值计数为0；门槛为2e-14。本轮平均检查的是推进实际使用的缩放选项。
- 12组64步最终有效DDF对照最大误差均为0；活动单元也为0。最终回归门槛为1e-12。
- 主作业36次运行全部正常退出；1/2 rank为host-staging数值验证，多rank未测性能。

额外生产网格作业 `616483`：基线、仅半warp、两项同时启用，各运行512步并在相同阶段写出checkpoint。半warp和同时启用候选，各自与基线的Header、Lattice、三级DDF数据/头文件共8个文件SHA256全部相同。

该Q19基线的covered存储含NaN，所以相同NaN相减仍使全valid差值L1/L2为NaN，不能只凭Linf=0声称全部有限；活动单元差值范数为0，完整文件指纹另确认两候选保存了与基线完全相同的NaN位模式。本次没有修改该基线状态或据此声称物理正确、长期稳定/收敛或所有ghost有限。[逐文件证据](../../runs/q19_batch_transfers_20261021/production_616483/checkpoint_sha_comparison.json)。该独立作业只用于回归，不混入主作业性能。

## 完整求解器性能

主作业在 whshare-agent-191 的 A100-PCIE-40GB 上执行，单rank/GPU、每次512步、report_int=256。输入为同一Q19模型的Re=3200、128³、最大Box128、max_level=2、regrid_int=32、interp_mode=0、非周期；关闭fixture、输出、收敛、逐值诊断及OSI嵌套细分计时。三轮四配置正/反/正顺序，固定同一可执行文件只切换初始化开关。各配对窗口的各层碰撞调用/单元数、平均调用及已报告的重建/边界计数相同。

## 判断与范围

Q19平均的进一步优化方向是批量16-lane分组；当前基线已经批量化，仍能使完整平均阶段再减少约23.74%、total约2.23%。该结果支持Q19的分组选择，不能据此把Q27也改成半warp。

插值继续采用现有批量空间线程路径。此次按q展开没有收益，增加了任务和重复的索引/几何工作；没有profiler分解，不将退化全部归因于某项。模式1/2仅验证数值，未做性能优化。

本轮Q19实现保留在独立快照，正式源码的模型默认仍为Q27。本实验是单独选择D3Q19表的受控短测，不宣称完成通用Q19生产模型的长期物理验证。数值/文件一致性范围如上，不回避相同covered NaN，也不将它误判为此次优化引入。

复现入口在实验根目录的submit_build.sh、submit_validation.sh、submit_production_check.sh及summarize.py、compare_production.py，实际命令与源/二进制冻结到各作业目录；一次性准备脚本冻结后删除，日志和数据保留。
