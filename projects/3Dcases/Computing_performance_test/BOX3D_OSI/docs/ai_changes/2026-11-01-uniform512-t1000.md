# 512³均匀Q27长程至t=1000

按用户要求对照AMR B，从静止运行单GPU FP32 D3Q27、Re1000、512³ lev0单Fab，dt=1/512，最大512000步、stop_time1000；末态输出速度ux/uy/uz及Q/Vorticity。使用此前正式程序的冻结副本，源码/配置/程序与输入均保存，不修改用户默认inputs。沿用amrex.the_arena_init_size=0避免预留池连续大块分配失败。场输出只在终点，checkpoint关闭，收敛不提前终止；report3200，guard8小时。

复用既有512³ MPI/guard提交命令，以环境参数表达短测和长程，submit.sh作为本轮提交快照保留。622114同尺寸32步输出预检退出0：两PlotFile时间0.0625、组件及数据长度检查通过，速度约1.6GiB、Q/涡量约1.1GiB；Arena使用高水位34094 MB，保留35126 MB，Pinned高水位1536 MB。这是短程I/O与容量验证，不替代t=1000精度验收。

正式长程作业622116已提交，尚未完成。最终需核对退出0、step512000/t1000、FinalState有限性、两PlotFile Header时间与文件完整性，再比较AMR相同物理终点的耗时/精度及完整峰值显存。仅末态输出与B每12800粗步输出的I/O频率不同，需分列perf.total和包含I/O的整次时间。1秒设备采样峰值不是精确活跃分配峰值；使用Arena终态高水位另报。
