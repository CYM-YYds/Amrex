# BOX3D_OSI 首次全局消重试验

## 目的与范围

从实际入口识别不可达历史实现，验证“先建立调用关系，再小步删除并量化”的方法。
基线提交为 `a7f9e8f`，开始时工作区干净。本次仅修改本算例的
[main.cpp](../../src/main.cpp) 和 [README](../../README.md)，不改变现役数值路径。

## 发现与改动

`main → Cycle2 → AdvanceLevel` 是现役推进链。
`RohdeCycle`、`JaberCycle`、`RohdeCycleMultiParticle`、`JaberCycleMultiParticle`
在本算例源码中的引用只有声明、函数自身递归和注释；没有入口调用或函数地址注册。
`config/Make.package` 直接将 main.cpp 编入可执行程序，无其他推进入口。
两套 Rohde 实现还保留了 FillGhostLevel 层级语义过时的注释，不能作为可随意切换的备选。

删除这四个函数、声明及对应旧入口注释块，共 244 行；历史实现保留在 Git。
保留 Cycle2 的函数体、生产阶段、锁步检查和日志字段；main.cpp 的 CRLF 保持不变。
README 同步实际调用链，并加入可重复执行的审计和分类处理方法。

## 验证

- 使用现有 `scripts/code_audit.sh`，相同默认参数和工具版本，在修改前后分别完整运行。
- 对比基线源文件：去除注释与空白后，`ReadInputConfig`、`main`、`Cycle2` 函数体一致；
  其余 src 文件逐字节一致。删除函数不含静态注册或文件级初始化副作用。
- `GEN_CCDB=0 ./scripts/compile.sh --no-submit` 成功，实际完成 main.cpp 的 CUDA+MPI
  增量编译及可执行文件链接。日志：`logs/compile/compile-20261011T104200.log`。
- `nm -C` 检查新可执行文件：保留 Cycle2，四个旧周期函数符号均不存在。
- `git -c core.whitespace=cr-at-eol diff --check` 通过；修改文档的本地链接已检查。
- 本次没有运行新的数值作业。验证结论限于不可达代码删除与现役源码保持一致，
  不代表多层 AMR、MPI 或物理结果已获得新的正确性证据，也没有测量运行加速。

## 后续候选与处理优先级

| 候选 | 当前证据 | 后续处理与验证要求 |
| --- | --- | --- |
| Kernels.H 三套 cumulant 函数 | 静态候选共 1335 NLOC；现役 Collide 分派为通用 BGK、优化 BGK 和 OSI BGK | 确认历史模型的保留用途及辅助函数依赖，另一个变更集处理；不要把不同物理模型强行合成一个实现 |
| main 输入读取与 ReadParameters 网格参数读取 | 两处读取 max_grid_size，且后者支持轴向覆盖 | 先列出默认值、数组补齐及覆盖优先级，再确定唯一参数所有者；验证缺省、短数组、轴向覆盖与多层配置 |
| 粒子插值/壁面片段 | jscpd 检测到较多相似代码；旧周期删除还暴露新候选 | 分清当前支持路径和历史模型，核对力、插值权重与运动副作用；更改现役路径需粒子算例回归 |
| A-B/OSI、手动诊断、AMReX 回调 | 具有不同布局、检查阶段或框架入口 | 有意保留；共享应限于明确等价的数学或搬运操作，保留阶段级对照的检查能力 |

每次新增功能先搜索已有实现，明确入口、数据所有者、模式和被替代路径；每个消重提交只处理
一个明确职责。对现役数值操作的合并需要逐 cell/逐 q 的阶段检查，不能用编译、checksum、
重复率下降或把代码移出扫描目录代替。大函数拆分与真正减少重复职责是两个不同目标。
