ReadCheckpoint已有canonical.ParallelCopy机制可复用，不新增数据结构/状态：拷贝完成后Gpu::synchronize并clear stored_old，使下一次OSI分配前释放读入DDF，避免三份DDF同时驻留。只提前结束派生临时缓冲生命周期，canonical及checkpoint格式不变。当前用户推进文件修改不动，实验用622116冻结源码加此处修复隔离编译；顶层正式可执行未替换。
