# 原18分量CUDA代码速度测试

按用户要求实测师兄原始实现，不改原件及正式求解器。复用flat_q27的生成/提交/分析入口，以--original与FLAT_ORIGINAL参数选择原模型，避免复制一套作业框架。实验保留原Re1600/Ma0.1、128线程和两个kernel正文；修补缺失错误检查头、未用q0初始化、旧未初始化计时统计，在相同时间戳上同时记录整数与浮点毫秒。

同节点单A100运行256³、原默认586³各两次，每次3000步、剔除首1000步。结果、计数口径和限制见[唯一详细报告](../../runs/temporary/flat_original/round1/report.md)。原整数毫秒与含halo分母存在系统性抬高，引用有效流体/高精度累计耗时。此为原18分量速度观察，不是D3Q27性能纪录或物理精度验收。

验证：四次应用/guard正常退出，原件哈希及碰撞/边界kernel正文逐字节一致；脚本语法、文档链接和限定diff检查通过。用户原件、输入、AMR判据及MLUPS文档的既有修改均不纳入提交。全部实验材料保留。
