# 按层复用 AMR 缓存并移除重复速度交换

## 目的与范围

BOX3D_OSI 每次重构原先清空并重建全部层的粗细传输、覆盖掩码和边界任务；
速度补边还在 `FillPatchTwoLevels` 已完成同层交换后重复调用 `FillBoundary`。
本次仅调整这些生命周期和重复工作，并提供默认关闭的判据准备计时。
不改变涡量差分、阈值、插值公式、完整平均下传、DDF 迁移或推进顺序。

## 实现与状态所有权

- 用 `InvalidateLevelCaches(lev)` 替换全局清空入口。DDF 定义/释放的层级回调使
  本层边界任务、两侧传输资源及相邻覆盖掩码失效；先释放绑定旧 Array4 的资源，
  再释放旧存储。OSI 同布局 Remake 保留原 DDF/phase，不触发该层存储失效。
- `level_cache_dirty` 是缓存重建需求的唯一标记：构造时全部置位；初始化、OSI
  存储定义、A-B 存储重建及 ClearLevel 置位；重构结束完成所有构建后清零。
  各层边界按本层标记重建，掩码/插值/平均按相邻两层标记的并集重建。
  显式标记能表达合法的空缓存，避免以空缓冲误判尚未构建。
- 保留现有构建函数、缓存所有者和相位更新机制，没有第二套构建路径。
  本次保留的是几何及存储绑定，不缓存跨步流场值。
- 细层速度补边只调用 `FillMacroPatch`；AMReX 26.06 内部在粗层插值后调用
  `FillPatchSingleLevel`，当前自填充配置会执行同层/周期 `FillBoundary`。
  level 0 的独立同层交换保留。
- `performance.regrid_detail_timing` 默认 false，一次读入 RuntimeParams；开启时
  分别测量宏观量、速度补边、涡量、打标/计数和缓存重建，并同步 GPU。
  三种新增缓存构建计数及原插值计数证明实际构建范围；关闭计时的零值是未测量。
