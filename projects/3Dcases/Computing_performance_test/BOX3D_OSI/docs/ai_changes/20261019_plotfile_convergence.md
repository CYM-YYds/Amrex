# job615364 收敛趋势重建

- 目的：运行覆盖参数关闭了收敛监测，从保存的速度 PlotFile 补算趋势。
- 范围：BOX3D_OSI 后处理，不修改求解器或运行配置。
- 实现：读取单块、无幽灵、128³ 的 Level-0 双精度三分量速度，按已有 `MeasureLevel0VelocityChange` 的公式计算相邻 3200 步的相对 L2 变化；验证 FAB 格式、有限值和 Cell_H 极值。不支持的布局直接报错。
- 输入：`runs/20261019_124153_job615364/plt_*`，实际 Re=3200，80 个流场，3200–256000 步；生成 79 个差分点，首点为 6400 步。没有初始流场，不能重建第一个间隔。
- 验证：用仓库 `.venv/bin/python` 完整执行脚本并检查 PNG；采样间隔全部为 3200。最终相对变化 0.07293155906，最小值 0.05044516666（240000 步），均大于配置参考阈值 1e-4。后期存在回升，未达到该稳态判据。这是 Level-0 指标，不是全 AMR 复合场证明。
- 输出：`data_post_processing/615364_Re3200_convergence.png` 与同名 CSV；CSV 按仓库现有忽略规则保留在本地。
