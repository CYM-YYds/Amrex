# D3Q27 一维OSI对照（临时实验）

师兄提供的main_ldc_nee.cu原件只读冻结为original.cu；prepare.py生成标准D3Q27 BGK实验副本，不代表原18分量实现性能。复用其一维OSI、SoA、单stream和壁面本地反弹；速度集/权重取自现有LbmLattice.H，Re1000/U0=0.05、有效流体256³、存储260³，修正逐步整数毫秒截断和统计分母，关闭输出。

先对128/256线程版本作64个非平衡单元×27方向的GPU碰撞与独立double参考比较（Linf≤2e-6），再与621699冻结AMReX程序在同节点交替各三轮，每轮1200步、200步报告，剔除首200步。原件、生成器、程序、编译日志、命令、输入、运行日志和结果均保留。

边界不同：实验为壁外一层全路反弹，AMReX在valid边界用NEE；不能比较逐点流场或直接归因整步加速。实验每步写压力/速度，AMReX碰撞不写；不同几何回绕与宏观量写回也是差异因素。128/256对照只在同一实验程序内归因block配置。未取得DRAM/occupancy硬件计数器，不把有效流量当实际带宽。
