# Roofline 小测试（2026-11-03，临时实验）

目的：先验证当前 GPU 计数器权限及单个预热后碰撞 kernel 的 Roofline 采集。仅运行单 GPU、单 rank、256³ 单层均匀网格，不代表多层 AMR 或多 GPU 性能。

程序通过当前构建入口检查后冻结，源码、GNUmakefile、输入、工作区差异、构建日志和 SHA256 位于本目录。构建检查为增量 make，目标已是最新，并非强制全量重编。正式配置及用户已有修改不变。

复用只读 checkpoint `../../../20261030_102153_job621699/chk00256000`；三次各推进 100 步，report_int=20，分析排除各轮首 20 步。基线保留程序自动 CUDA 事件采样。第三轮保存最终场和 checkpoint，所有轮保留最终状态有限性检查日志；该检查不代表物理解收敛或数值等价。

随后 Nsight Compute 尝试跳过 16 个匹配的碰撞 kernel，采集一个 kernel；权限失败时保留原始错误，不修改驱动权限。所有命令及实际覆盖参数由各子目录 command.txt 记录，实际退出码以 job 目录 status.tsv 为准。

保留范围：程序、源码与配置快照、构建日志、命令、原始输出、最终场、checkpoint、报告和复现入口全部保留。原历史 checkpoint 仅链接引用，不清理历史数据。
