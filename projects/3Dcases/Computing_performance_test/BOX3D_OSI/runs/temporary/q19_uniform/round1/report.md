# 标准D3Q19密度BGK同节点对照

2026-10-31；临时实验，作业621996，whshare-agent-50，单张A100-PCIE-40GB。按用户选择双方均改为标准密度BGK，包含q0；师兄原件及正式AMReX Q27默认不改。原版师兄压力模型仅推进q1–18，其6650 MLUPS不能视为此标准Q19结果。

## 参数与计时

有效256³、存储260³、FP32、128线程/block、Re=1000、U0=0.05、有效Ma≈0.08660，静止启动。方向/权重使用AMReX D3Q19 ORDER0；rho=Σf，u=Σ(fe)/rho，feq=w*rho*(1+3eu+4.5eu²−1.5u²)。CUDA12.8、GCC11.3、SM80、O3/fast_math。

每次1200步、report=200，首200步预热不统计，各模式三次共3000稳态步；顺序Q27/Q19/flat，flat/Q19/Q27，Q19/Q27/flat。关闭场输出、checkpoint、收敛检查。MLUPS按有效更新总量/总时间计算；分项为GPU事件，不与total直接相加。以下范围是三次应用平均ms/步范围。

## 验证与结论边界

数值门槛先于性能运行。AMReX Q19在64³、max_grid_size=16、160步、非平衡初值的周期/非周期A-B与OSI对照中，19分量valid/active L1/L2/Linf均为0，末态有限。师兄副本64个非平衡采样单元的19分量double碰撞参考最大误差1.22530e-7；16³全网格在phase=0,1,19,20,41,1200的映射完全一致，碰撞最大误差1.51714e-7、边界2.35936e-9，均小于2e-6。15个应用退出码均0。没有做跨程序全场逐值等价或长期精度验证，也不覆盖Q19 AMR/多GPU。

Q19令AMReX吞吐较同节点Q27提高48.97%、整步时间减少32.87%；相对师兄标准Q19副本，吞吐达到93.96%，整步时间长6.42%。碰撞事件区间并未更慢；边界多约0.244 ms/步，与整步差约0.185 ms/步相符，但不能唯一归因。两套Q19碰撞核均127寄存器/线程，无spill；无Nsight Compute计数器，不能推断实际DRAM带宽或occupancy。

AMReX使用grown-Fab逐轴OSI、NEE边界、C++20/RDC；师兄副本使用flat全环OSI、外置反弹/顶盖修正、C++17/无RDC，并额外写压力及三分量速度。边界位置、阶段顺序和编译不同。师兄事件查询位于chrono统计区间外，AMReX事件收集包含在total，仍有小的计时范围差异。师兄副本旧Ma宏未使用，实际由U0=.05决定。不能把此对比解释为纯框架开销。

## 显存与复现

AMReX整次应用The Arena使用高水位：Q19为1984 MB，Q27为2521 MB；两者Arena保留容量均30254 MB，三轮一致。保留容量不是活跃分配峰值，也不是全设备显存。师兄直接cudaMalloc，全进程峰值未采集。
