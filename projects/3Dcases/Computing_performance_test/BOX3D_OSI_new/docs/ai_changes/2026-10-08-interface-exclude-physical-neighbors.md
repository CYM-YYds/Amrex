# 排除物理域外邻居的 interface 判定

目的：物理边界本身不应触发粗细界面分类；域内粗细交界仍保留。

影响范围：BOX3D_OSI 的粗层 interface 掩码、界面平均缓存及其推进范围。

主要改动：使用 `Geom(lev).growPeriodicDomain(1)` 限制掩码邻域和几何平均缓存搜索范围；排除非周期域外邻居，保留周期邻居。物理边界单元仍可因域内未覆盖邻居成为 interface。不改变 Boundary 跳过 covered 的策略。
